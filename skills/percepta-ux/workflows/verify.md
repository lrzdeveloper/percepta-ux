# Verify

Read [Review loop](../references/review-loop.md) before assessing the change. Start with the promised change and what would demonstrate it. Inspect the actual
artifact and run checks available for this scope. For rendered work, examine a
representative narrow layout, key state, input path, and recovery case as relevant.
Read [Standards](../references/standards.md) for scoped conformance claims.

Report each important claim as supported, contradicted, or unverified, with its
evidence or missing check. Distinguish source inspection, runtime interaction,
assistive-technology checks, profiling, and research. Repair defects only when
fixes are authorized; verification alone remains advisory.

Done: each material claim has a check result or exact evidence gap. Missing tools
produce a bounded result with remaining checks, not a production-readiness claim.
