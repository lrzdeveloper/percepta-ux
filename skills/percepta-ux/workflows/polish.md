# Polish

Inspect the existing interface and preserve its task, identity, factual content,
and interaction contracts. Read [Visual craft](../references/visual-craft.md) for
hierarchy, type, spacing, alignment, semantic color, icons, and responsive behavior.
Keep labels and density when they serve the task.

Implement requested refinements using existing primitives. Include material task
or feedback defects within scope. When tools permit, inspect the rendered result
at representative widths and affected states, fix visible defects, and check again.
A small alignment fix does not require a new design direction or full UX workshop.

Done: the requested refinement is concrete, coherent with the product, and checked
where possible. Separate source checks from rendered or interaction checks.
