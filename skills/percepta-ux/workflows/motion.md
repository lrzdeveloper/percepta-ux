# Motion

Read [Motion](../references/motion.md) before specifying what the movement communicates:
trigger, state transition, interruption, focus, alternative inputs, reduced motion,
and actual success/error/unknown signals. Adapt pacing to frequency and context.

For tactile controls, changing labels, hold/undo, file drop, or durable results,
read [Interaction patterns](../references/interaction-patterns.md). Separate an
operational control from an expressive marketing or exported motion asset.

Done: the requested specification or implementation keeps state and control usable
without hover, dragging, sound, or animation alone. Progress reflects actual work;
claimed outcomes reflect the service contract.
