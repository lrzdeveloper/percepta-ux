# Clarify

Read [UX copy](../references/ux-copy.md) before rewriting. Inspect the affected task and state; preserve
product terms, facts, variables and commitments, then rewrite the language that
prevents understanding or recovery. Identify whether the request is a proposal
or an authorized source edit.

Give the person the important fact, the available action, and any consequence
needed for an informed decision. Keep pending and unknown outcomes truthful.
A compact before/after table is useful for multiple strings; a single label needs
only the replacement and its reason.

Check the copy in context, including correction and relevant localized or access
states. Use [Review loop](../references/review-loop.md) for implemented changes.

Done: concrete wording resolves the ambiguity while preserving meaning and the
real interaction contract; actual checks and remaining gaps are clear.
