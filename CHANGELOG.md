# Changelog

- Fifteen workflows for interface review, implementation, interaction design,
  copy, adaptation, resilience, research, ethics and verification.
- Twenty-five linked guides covering UX psychology and practical execution.
- Public npm distribution, npm/skills install buttons and live package/CI badges.
- GitHub installation through npx or skills, agent/scope selection, offline command
  discovery and prompt generation.
- Full-context prompt preparation with entrypoint, workflow and linked guidance.
- Local context-loading, word-count and opaque-sRGB contrast helpers.
- Modular research protocols, explicit evidence limits, outcome/recovery contracts
  and optional-runtime fallbacks.
- Automated CLI, helper, package, format and license checks with reusable behavioral
  scenarios and synthetic fixtures.
- Publication path and credential-pattern checks across Git history, with local
  commit/push hooks and a dedicated CI job.
- MIT licensing for original code and instructions, with a bundled runtime license
  and preserved third-party notices.
